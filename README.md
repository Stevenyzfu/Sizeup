# Sizeup

AI-powered market research tool for startup founders.

Generate investor-ready market sizing reports — TAM/SAM/SOM estimates,
CAGR projections, and competitive snapshots — in under 30 seconds.

## Status
🚧 In development — Phase 1 (static shell) complete.

## Tech stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Anthropic Claude API (planned)

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000
